# keiba — 競馬予想・分析アプリ（JRA）

netkeiba の過去レースデータを集めて SQLite に保存し、統計分析・予測モデル・
回収率重視の買い目提案・バックテストを行う個人用アプリです。
毎週、土日の朝に全レースを自動で予想し、日曜の夜に結果と答え合わせをしてモデルを学習し直します。

> **利用上の注意**：netkeiba の利用規約を確認し、個人で使う範囲にとどめてください。
> このアプリはリクエストの間隔を最低2秒（既定3秒＋揺らぎ）あけ、並列アクセスをせず
> （別のプロセスが同時に動いてもロックで1本ずつ）、取得したページをキャッシュして同じページを取り直しません。
> 取得したデータやキャッシュを他の人に配らないでください。馬券の購入は自己責任でお願いします。

## 1. セットアップ（Windows）

1. Python 3.11 以上をインストール（インストーラで「Add python.exe to PATH」にチェック）
2. このフォルダで PowerShell を開いて：

```powershell
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m pytest -q          # テスト（全部 passed になればOK）
```

## 2. はじめの流れ

```powershell
# (1) まず1か月分で試す（約1〜2時間）
python -m keiba collect --start 2026-10-01 --end 2026-10-31

# (2) 直近5年分を取得（数日かかります。止めても続きから再開）
python -m keiba collect
#    急ぐときは、まずレース結果だけ → あとで馬の詳細・確定オッズ
python -m keiba collect --no-horses --no-odds
python -m keiba collect

# (3) モデルを学習（直近6か月で検証）して採用
python -m keiba train --force

# (4) バックテスト（例：2025年以降を1か月ごとに学習し直して検証）
python -m keiba backtest --start 2025-01-01

# (5) レース予想
python -m keiba predict --date 2026-11-22 --venue 京都 --race 11 --budget 10000

# (6) 画面
streamlit run app.py         # または scripts\windows\run_app.bat
```

取得の目安（5年分）：レース約17,000件で約20時間、馬の詳細 約3〜4万頭で2〜3日、
確定オッズは1レース5回の取得が必要なので、`config.yaml` の `scraper.final_odds_since` で期間を絞っています（既定 2024年以降）。

## 3. 毎週の自動処理（タスクスケジューラ）

```powershell
cd scripts\windows
powershell -ExecutionPolicy Bypass -File .\register_tasks.ps1
```

| タスク | いつ | 内容 |
|---|---|---|
| keiba-auto-predict | 土・日 8:40 | 前日までの結果を取り込み → その日の全レース（障害を除く）を予想して DB に保存、`data/reports/predictions_日付.txt` に出力 |
| keiba-weekly | 日 21:10 | 今週の結果・確定オッズ・新しい馬の血統を取り込み → 予想の答え合わせ（◎の勝率・印別成績・買い目の回収率・市場オッズとの比較）→ モデルを学習し直し → 検証成績が悪化していなければ採用 → `data/reports/weekly_日付.md` |

- PCが寝ていたら起こして実行し、電源が切れていたら次に起動したときに実行します。
- 結果は画面の「データ更新」タブの「週次レポート・自動予想」でも見られます。
- 止めるとき：`Unregister-ScheduledTask -TaskName "keiba-*" -Confirm:$false`

### 「学習して精度を上げる」しくみ
1. 毎週、新しいレース結果がデータに加わり、そのデータでモデルを学習し直します（騎手・血統・コースの成績も最新になります）。
2. 学習のたびに、学習に使っていない直近6か月で成績を測り、今のモデルより悪くなった場合は採用しません。
3. 期待値の計算に使う「モデルと市場オッズの合成比率 α」も毎回検証データで決め直します。
   モデルが市場より当たるようになれば α が上がり、モデルの意見がより強く買い目に反映されます。
4. 週次レポートに、自動予想の答え合わせ（印ごとの成績・買い目の回収率）が残るので、改善の様子を追えます。

## 4. 画面（4つのタブ）

| タブ | できること |
|---|---|
| データ更新 | DBの件数・期間、期間を指定した取得（バックグラウンド）、モデルの学習と成績の履歴、週次レポート |
| 統計分析 | 切り口（コース・枠・馬番・脚質・産地・生産者・所属・父・母父・騎手・調教師・天候・馬場・人気・オッズ帯・間隔・距離変化・昇級降級 など）ごとの勝率・連対率・複勝率・単勝/複勝回収率・出走数。組み合わせで絞り込み可。出走数が少ないものは「参考値」と95%信頼区間 |
| レース予想 | 日付・競馬場・R番号・予算 → 展開予想／各馬の推定勝率・複勝率・印・根拠／期待値で選んだ買い目と配分（1/4ケリー）または見送り推奨／荒れ度0〜100と穴馬候補 |
| バックテスト | walk-forward 予測で、買い方（◎単勝、1番人気、券種別の期待値ルール、総合ケリー、自分で作るルール）ごとの回収率・的中率・最大ドローダウン・収支の推移 |

スマホからは、同じ Wi-Fi で `streamlit run app.py --server.address 0.0.0.0` として、
PC の IP アドレス:8501 を開いてください。

## 5. コマンド一覧

```
python -m keiba collect      過去データの取得（--start/--end/--years、--no-odds/--no-horses/--no-jockeys）
python -m keiba stats        集計（--by 脚質 --filter venue=東京 --filter surface=ダート --filter style=差し,追込）
python -m keiba train        学習（--valid-from、--force で採用）
python -m keiba backtest     バックテスト（--start、--step 学習し直す間隔の月数）
python -m keiba predict      レース予想（--date --venue --race --budget）
python -m keiba auto-predict その日の全レースを予想して保存
python -m keiba weekly       週次処理（取り込み→答え合わせ→再学習）
```

## 6. しくみの説明

- **脚質**：通過順位から判定。最初のコーナーで1番手＝逃げ、最後のコーナーで頭数の1/3以内＝先行、2/3以内＝差し、それより後ろ＝追込。
- **特徴量**：馬の過去成績（近走の着順・タイム差・上がり順位・位置取り・条件別成績）、騎手・調教師・父・母父の成績、前走からの間隔・距離変化・昇級降級・乗り替わり、レース内での相対値、前に行きたい馬の数など約60個。すべて「そのレースより前」のデータだけから計算し、当日のオッズ・人気は使いません。
- **モデル**：LightGBM で「勝つ確率」と「3着以内の確率」を予測し、1レースの合計が勝率=1・複勝率=3になるように揃えます。学習・検証は日付で分けます。
- **買い目**：期待値＝推定確率×オッズ。組み合わせの確率は推定勝率から Harville 法で計算。確率はモデルと市場オッズの合成（上記 α）を使い、券種ごとの最低確率で極端な穴を除外。配分は 1/4 ケリー、1レースの上限は予算の50%。
- **荒れ度**：1番人気のオッズ、オッズの割れ具合、予測の割れ具合、コースとクラスの過去の波乱率（4番人気以下の勝利の割合）、頭数、馬場状態、予想ペースを重み付けして0〜100に。

設定はすべて `config.yaml` にあります。テーブル構成は [docs/schema.md](docs/schema.md)。

## 8. 分かっている課題

- netkeiba のページの作りが変わると、取得・解析が失敗することがあります（テストと `data/logs` のログで気づけます）。
- バックテストは「確定オッズ」で買う判断をしているため、実際（締切前のオッズ）より良く見える可能性があります。
- 自動予想は朝の時点のオッズで買い目を出します。締切直前にはオッズが変わるので、画面で予想し直してから判断してください。
- 障害レースはモデルの対象外です。
- 組み合わせの確率（Harville法）は、人気馬が2・3着に来る確率をやや高めに見積もる傾向があります。
